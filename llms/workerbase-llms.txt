# Workerbase

> Workerbase is a Munich-based connected-worker / frontline-execution platform for manufacturing. It bridges ERP/MES planning and shopfloor operations with digital work instructions, dynamic task orchestration, quality and maintenance workflows, an industrial smartwatch, and AI agents for the shopfloor. Customer documentation is login-gated; the public developer surface is the first-party JavaScript SDK and Node-RED nodes on npm, which speak to a per-tenant instance REST API (task manager, user management, work instructions, databases, connectors, functions).

## Developer surface

- [Workerbase SDK for JavaScript (npm)](https://www.npmjs.com/package/@workerbase/sdk): tasks, users, roles, skills, locations, media, databases (+items), connectors, functions, actions, buttons, workflow steps; runs inside Workerbase Functions with an access token
- [SDK documentation (login required)](https://workerbase.zendesk.com/hc/en-us/articles/14805311093277-Workerbase-SDK-for-JavaScript)
- [Node-RED nodes (npm)](https://www.npmjs.com/package/node-red-contrib-workerbase): create/announce tasks, message users, trigger work instructions against a Workerbase instance (/taskmanager, /usermanagement, /workinstructions endpoints)
- [Help Center (login required)](https://workerbase.zendesk.com/hc/en-us)
